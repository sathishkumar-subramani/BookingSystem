# Arangam mobile (Expo / React Native)

Android-first app for customers and hall owners. Admin tools stay on the web.

- **Customers:** explore with a date strip and session picker, "Halls near me" (phone GPS), hall page with the availability calendar, 10-minute hold, test payment, booking ticket with the petal celebration.
- **Owners:** upcoming bookings, balance-due list (mark received), calendar to block dates.
- Same Lottie files as the web (`assets/lottie`, generated by `../shared/lottie/build.mjs`), same colours (`src/theme.json`, copy of `../shared/theme.json`), same API types (`src/api/types.ts`, copy of the web's).

## Run it on your phone (Expo Go)

```bash
cd mobile
npm install
npx expo start          # scan the QR with Expo Go
```

The app talks to `EXPO_PUBLIC_API_URL` (see `.env.example`). It defaults to the Render API. On Expo Go, `localhost` means the phone itself — use your laptop's LAN IP if you run the API locally.

## Build an APK (no Android Studio)

```bash
npm i -g eas-cli
eas login
eas init                # once: creates the Expo project and writes its id into app.json
eas build -p android --profile preview
```

EAS builds in the cloud and gives a download link for the APK. `eas.json` already points the build at `https://arangam-api.onrender.com/api`.

## Layout

```
src/
├── app/            screens (expo-router): (tabs)/ explore · bookings · account, hall/[slug], results, checkout/[id], booking/[id], login, register, owner/calendar
├── api/            RTK Query endpoints, secure-store session with single-flight token refresh, shared types
├── components/     ui (text, buttons, chips, motion), Anim (Lottie), HallArt + SilkBorder (SVG), Calendar, HallCard
├── store/          Redux store + auth slice
└── utils/format.ts ₹ formatting, dates (copy of the web's)
```
